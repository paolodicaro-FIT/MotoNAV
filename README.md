# MotoNAV TEST 0.2

Prototipo grafico blu/verde glow, con import GPX, GPS e routing online dimostrativo.

## Avvio
Pubblicare i file su GitHub Pages (HTTPS) e aprire TEST.html. Per GPS serve HTTPS o localhost.

## Limiti
Richiede internet per mappa e routing; niente navigazione turn-by-turn, voce o offline. Il servizio OSRM demo non è adatto a uso produttivo. Non usare come unico navigatore.
